能力层 · 标准与认证

FUN Certified

联盟标准、审核、培训、认证章。对外表述为"标准与认证体系"，不是产品。

FUN Certified 是横向能力：认证章盖在具体咖啡、报告、证书上，可服务任何产品线，不绑定 FUN AI。

对外怎么展示

网站"我们做什么"三块并列，但语法分开：

  • FUN AI：产品
  • FUN Certified：标准与认证
  • 产业连接：合作、产区、课程

认证用认证章 + "标准/认证"字样，不用产品卡样式。

三种标识的用法

  • FUN 母品牌：官网、封面、页脚
  • FUN AI：产品界面、AI 物料
  • FUN Certified：贴在咖啡、报告、证书上
结构提示：若 FUN Certified 对外提供第三方认证并收费，需保持与被认证产品供应方的独立性（ISO/IEC 17065 公正性原则）。在此之前，只宣称"联盟标准 / 内部认证"，不称第三方认证。
